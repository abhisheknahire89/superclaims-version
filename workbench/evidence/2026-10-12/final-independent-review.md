## Reviewed positive controls and limits

Local sessions persist only token/CSRF hashes and reload current DB roles. Password hashing uses per-user salted scrypt; lockout updates serialize on credential row. Cookie mutations require CSRF; login origin/body limits and HttpOnly/SameSite/production Secure flags are present. Tenant admin writes require password confirmation, serialize per tenant, preserve role history and revoke sessions. New tenant tables force RLS; transcription/admin/anchor/deadline history is append-only. Clinical resolution permissions belong only to medical officers.

Query replies lock claim then query, require active same-claim evidence and an open item, mark evaluation stale and enqueue processing without resolving material conflicts automatically. Approved local letter export is gated. Nonresponse reminders do not dispose claims. Job handlers hold the leased row through transactional success; the actual process-kill test proves uncommitted evaluations roll back and an expired attempt recovers. Store exclusive hard-link publication prevents application overwrite, and reads require matching sidecar checksums. These are local controls; the host administrator can replace DB and objects, as ADR-17 explicitly explains.

Residual cleanup issue observed during the negative restore probe: rejecting a restored original after pg_restore left the owner connection open until interpreter cleanup (psycopg ResourceWarning), because exceptional post-restore verification does not close the connection in finally. The deliberately new failed target database/object tree also remains for diagnosis. Severity P2 operational cleanup, not an integrity bypass: success is refused and no existing target is overwritten. Prefer try/finally owner.close and clearly identify failed new targets in CLI error handling.

NOT RUN by this reviewer: full product suite/pack, browser workflows/accessibility/performance, clean checkout, exhaustive parser fuzzing, resource-exhaustion load, hostile HTTP clients, external security audit or any real claim. Parent milestone evidence owns those broader tests. No claim of production readiness or regulatory approval follows from this review.
