# ADR-15 — Local configuration administration

Accepted 12 October2026. Immutable versions retain the original schema/migrations. Local CSV/XLSX imports are bounded JSON-pointer patches to a selected configuration, previewed/diffed and validated before drafting. They never import policies, members or external-system data. XLSX formulas are rejected. Policy effective dates in the body and version metadata must agree; the old configuration test now sets both dates, retaining four-eyes/effective-date assertions.

Calculation ordering previously stored metadata while the engine executed a fixed order. The engine now follows validated line and claim ordering. Safety dependencies remain compulsory: gates first, duplicates and nonmedical rules before tariff/packages, room cap before proportionate, lines before claim rules, co-pay before SI and rounding last. Catalogue review rules and package consumption are additional fixed stages. Historical money traces are unchanged.

Replay is a synchronous read-only preview (the previous OpenAPI promised an unimplemented result endpoint). Policy, tariff, NME and checklist candidates compute deltas; workflow candidates preview approval settings; classifier candidates replay source-page classification/extraction counts. Neither latter preview claims to change payable. Publishing defaults to no queued retrospective re-evaluation; explicit eligible-open-claim application marks stale and queues reconciliation. Policy references update only under that explicit setting. Configuration publications serialize by tenant/artifact lock. Workflow approval limits apply to role assignments when published.

Pre/post service dates and missing implant invoice abstain for review rather than deducting without conclusive evidence. Exclusions, duplicate claims and LOS norms are review cues, never automatic rejection. Package cap deductions cite tariff authority and actual component evidence; consumed components cannot receive tariff/room/proportionate caps again. Clinical summaries contain source observations and citations only. Deadline clocks require supervisor action and do not dispose claims. Norms/exclusions remain customer-owned synthetic configuration.
